* 키오스크 장시간 방치 상황을 처리하기 위한 `useIdleTimer` Custom Hook 구현
* 기본 무입력 제한시간을 3분으로 설정
* `click`, `touchstart`, `pointerdown`, `keydown` Event를 사용자 입력으로 감지
* 사용자 입력 발생 시 무입력 Timer 초기화
* 3분 동안 입력이 없는 경우 `resetAll()` 실행
* 로그인·결제·이용권·예약 등 사용자 관련 상태를 전체 초기화
* 자동 초기화 후 `/` Home 화면으로 이동
* Home 화면에서는 불필요하게 Idle Timer가 동작하지 않도록 제외
* `KioskLayout`에 Idle Timer를 적용하여 Kiosk 전체 화면에서 공통 동작하도록 구성
