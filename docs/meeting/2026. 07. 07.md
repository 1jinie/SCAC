## 🎯 결정 사항 & Action

#### UI/UX 개선
- 주요 사용자 화면의 UI를 전면 개선하여 사용자 접근성과 직관성을 높이기로 결정
- Figma 프로토타입을 기반으로 실제 사용자 플로우를 검증하며 화면을 구성하기로 함

#### 결제 및 좌석 배치 화면
- 결제 화면 디자인을 전면 수정하여 정보 전달력을 개선
- 좌석 배치도 디자인을 확정하고, 표시 정보는 **좌석 번호 및 스터디룸 번호만 제공**하기로 결정
- 사용자 ID 및 남은 이용시간은 제외하기로 결정
- 결제 취소 버튼 색상을 프로젝트 디자인 시스템에 맞게 확정
- 팝업 및 모달의 배경 Blur 투명도를 전체 화면에서 동일하게 적용하기로 결정

#### 관리자(Admin) 화면
- 관리자 전용 UI 및 관리 화면 제작 방향을 확정
- 관리자 기능을 고려한 화면 레이아웃을 우선 설계한 후 세부 기능을 구현하기로 결정
