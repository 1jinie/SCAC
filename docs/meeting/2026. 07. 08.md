## 🎯 결정 사항 & Action

#### UI 및 화면 설계
- 스터디룸 예약 화면을 최종 확정하고 제작 완료
- 로그인 및 회원가입 화면을 전면 수정하여 디자인을 통일
- 메인 로고 디자인을 확정
- 로그인 버튼 디자인을 전체 화면에서 동일한 스타일로 적용
- 메인 화면에 **외출 버튼**을 추가하기로 결정
- 사용자 정보 입력 화면에는 별도의 로그인 버튼을 추가하지 않기로 결정
- 예외 상황 처리를 위한 **에러 페이지**를 제작하기로 결정

#### 내 정보(My Page)
- 내 정보 화면에 표시할 데이터를 아래와 같이 확정
  - 잔여 이용시간
  - 이용권 유형
  - 회원 ID(전화번호)

#### 프로토타입
- Figma Prototype을 최종 완성
- 프로토타입 테스트 결과 하단 영역이 일부 잘리는 현상을 확인
- 모든 화면 하단에 동일한 여백을 적용하여 UI를 수정하기로 결정

#### 개발 환경
- 팀 공용 데이터베이스를 구축하고 접속 정보를 공유
- 프론트엔드 개발을 위한 GitHub 저장소를 생성
- 프론트엔드 기능별 담당자를 확정하여 개발을 진행하기로 결정
