### 👤 장원진
### 좌석 / 예약 / 입실·퇴실 · Git 관리

#### TicketUsage Priority

- 전일 결정한 복수 이용권 사용 우선순위 Backend 반영
- 입실 준비 시 이용권 유형과 상태에 따른 우선순위 조회 구현

#### 이용권 조회 우선순위

1. 현재 `USING` 상태인 기간권
2. `READY` 상태인 기간권
3. `READY` 상태인 시간권

- 동일 조건의 이용권은 구매일이 오래된 이용권부터 조회하도록 구성
- 사용 가능한 기간권이 존재하면 시간권보다 먼저 적용하도록 보완

#### 기간권 구매

- 기간권 구매 시 현재 사용 중인 이용권 조회
- 현재 시간권을 사용 중인 경우 해당 시간권을 `READY`로 변경
- 새로 구매한 기간권을 즉시 시작할 수 있도록 처리
- 기간권의 `validDays`를 이용하여 종료시각 설정

#### Check-in / TicketUsage

- `TicketUsage`에 시간권을 `READY` 상태로 되돌리는 기능 추가
- `EXPIRED`, `CANCELED` 상태 이용권은 READY 전환 불가 처리
- 입실 시 READY 기간권의 사용 시작 처리
- 퇴실 시 사용 중이던 시간권을 READY 상태로 변경
- 남아 있는 시간권을 다음 입실에서 다시 사용할 수 있도록 보완
- 다음 이용권 활성화 과정에서 시간권·기간권 시작 로직 분리
- 기간권 우선 사용 정책과 Check-in 연동 보완 진행
- Check-in 관련 전체 흐름은 추가 검증 필요
