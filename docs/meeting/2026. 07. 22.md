## 🧩 JPA / MyBatis 역할 구분

| 상황 | 사용 기술 | 이유 |
| --- | --- | --- |
| 회원 등록·수정·삭제 | JPA | 기본 CRUD를 빠르게 구현하기 용이 |
| 이용권 생성·수정 | JPA | 엔티티 중심 관리에 적합 |
| 결제 내역 저장 | JPA | 연관관계 및 트랜잭션 처리에 유리 |
| 예약 등록·취소 | JPA | 상태 변경 로직 관리에 적합 |
| 메모 관리 | JPA | 상태 변경 중심의 CRUD에 적합 |
| 관리자 매출 통계 | MyBatis | 집계 및 그룹 조회 SQL 작성에 유리 |
| 조건이 많은 로그 검색 | MyBatis | 동적 SQL 작성이 용이 |
| 여러 테이블을 조합한 관리자 목록 | MyBatis | 조회 결과를 DTO에 직접 매핑하기 편리 |
