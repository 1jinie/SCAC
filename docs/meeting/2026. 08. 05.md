- 당일 매출액 집계 기준과 DB 컬럼 사용 방식 추가 검토

#### SystemLog Controller

- 중복되어 있던 관리자 로그 Controller를 `AdminSystemLogController`로 통합
- 전체 시스템 로그 조회 Endpoint 유지
- 전체 좌석 로그 조회 Endpoint 통합
- 특정 좌석 로그 조회 Endpoint 통합
- 중복 `AdminLogController` 삭제

#### SystemLog Stability

- 회원 제재 자동 해제 메서드에 `@Transactional` 적용
- 회원 상태 변경과 정지 종료일 초기화를 하나의 Transaction으로 처리
- SystemLog 저장에 `Propagation.REQUIRES_NEW` 적용
- 기존 비즈니스 Transaction과 별개의 Transaction에서 로그를 저장하도록 변경
- SystemLog 저장 실패 또는 Rollback이 기존 비즈니스 로직에 미치는 영향 분리
- SystemLog 생성 시각에 `@CreationTimestamp` 적용
- 생성 시각 컬럼의 `insertable = false` 설정 제거
- 좌석 로그 사용자 전화번호 조회 과정의 N+1 문제 개선
- 로그의 사용자 ID를 수집한 후 `findAllById()`를 사용하여 사용자 정보를 일괄 조회
- 좌석 로그 응답 변환 공통 메서드 구성
