### 👤 장원진
### 좌석 / 예약 / 입실·퇴실 · Git 관리

#### Check-in Scheduler

- 시간권 잔여시간을 1분마다 차감하는 로직 보완
- 잔여시간이 남아 있는 경우에만 차감하도록 조건 수정
- 시간권 잔여시간이 소진된 경우 자동 퇴실 처리
- 기간권의 종료 시각이 지난 경우 자동 퇴실 처리
- 시간권과 기간권의 자동 퇴실 조건 분리
- 자동 퇴실 공통 로직을 별도 메서드로 분리
- 자동 퇴실 시 Check-in 상태를 퇴실로 변경
- 자동 퇴실 시 좌석 사용자 정보 해제
- 자동 퇴실 시 TicketUsage 만료 처리

#### Check-in / Seat Refactoring

- 사용하지 않는 이용시간 계산 메서드 제거
- 사용하지 않는 변수 및 Import 제거
- 관리자 강제 퇴실 과정의 불필요한 TicketUsage 조회 제거
- 이용시간 정보가 없어도 관리자 강제 퇴실이 가능하도록 수정
- 강제 퇴실 시 Check-in 퇴실 및 좌석 해제가 정상 처리되도록 보완

#### Admin Seat Backend

- 선택 좌석의 현재 이용자 조회 API 구현
- 현재 이용자의 전화번호와 이용권 정보 조회
- 시간권의 남은 이용시간 제공
- 기간권의 남은 이용일수 계산
- 전체 좌석 이용 로그 조회 API 구현
- 특정 좌석 이용 로그 조회 API 구현
- 좌석 입실 시 SystemLog 기록
- 좌석 퇴실 시 SystemLog 기록
- 관리자 강제 퇴실 시 SystemLog 기록
- 좌석 로그를 최신순으로 조회하도록 Repository 메서드 구성

#### Admin Seat Frontend

- 관리자 좌석 상태 수동 변경 API 연결
- 관리자 강제 퇴실 API 연결
- 선택 좌석 현재 이용자 API 연결
- 관리자 좌석 화면의 임시 사용자 데이터 제거
- 전체 좌석 이용 로그 조회 연결

- 로그인 성공 시 Access Token 및 관리자 정보 저장

#### Admin Dashboard

#### Admin User / Log / Reservation

- 관리자 회원관리 화면의 회원 제재 API 연결
- 회원 상태 변경 결과를 화면에 반영
- 관리자 시스템 로그 정적 JSON 데이터 제거
- 전체 시스템 로그를 실제 API로 조회
- 로그 상세 화면을 실제 API 응답과 연결
- 로그 검색·필터·페이징을 실제 조회 데이터 기준으로 적용
- 관리자 스터디룸 예약 더미 데이터 제거
- 실제 스터디룸 및 예약 목록 API 연결
- 관리자 예약 취소 API 연결
- 예약 취소 후 최신 목록 재조회
- 관리자 장치관리 화면의 미정의 데이터 오류 수정

#### SystemLog AutoLog

- 공통 `@AutoLog` Annotation 구현
- AOP 기반 `SystemLogAspect` 구현
- Annotation이 적용된 메서드의 실행 결과를 SystemLog로 자동 기록
- Security Context에서 현재 사용자 또는 관리자 ID 조회
- HTTP 요청에서 접속 IP 주소 조회
- 정상 처리 시 지정된 로그 레벨 기록
- 예외 발생 시 `ERROR` 레벨과 오류 메시지 기록
- 로그 기록 실패가 기존 비즈니스 로직에 영향을 주지 않도록 예외 분리

#### AutoLog 적용

- 관리자 회원 제재 처리
- 관리자 강제 퇴실 처리
- 관리자 좌석 상태 수동 변경
- 관리자 계정 생성
- 관리자 계정 권한 및 비밀번호 수정
- 관리자 계정 삭제

#### User Penalty Scheduler

- 정지 상태이며 정지 종료일이 지난 회원 조회 기능 구현
- User Entity에 제재 해제 메서드 추가
- 제재 해제 시 회원 상태를 `ACTIVE`로 변경
- 제재 해제 시 정지 종료일 초기화
- 제재 기간 만료 회원 자동 해제 Service 구현
- 매시 정각마다 실행되는 회원 제재 해제 스케줄러 구현
- 자동 해제된 회원 수 기록
- 회원 제재 자동 해제 시 SystemLog 생성
- 스케줄러 실행 오류에 대한 서버 로그 처리
- 별도 Scheduling 설정을 통해 Spring Scheduling 활성화

#### Payment Dashboard

- 당일 매출액 집계를 위한 Repository Query 구현
- 결제 상태가 `PAID`인 당일 승인 결제만 합산
- 전체 결제 목록을 조회한 후 합산하던 방식 개선
- 집계 결과가 없는 경우 `0` 반환
