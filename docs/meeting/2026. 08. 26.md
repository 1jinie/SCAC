### 👤 장원진

#### Meeting Room / Concurrency

- 동일 스터디룸에 동시에 예약 요청이 들어올 경우 중복 예약이 생성될 수 있는 문제 수정
- `MeetingRoomRepository`에 비관적 Write Lock 적용
- `findByIdForUpdate()` 추가
- 예약 생성 전 대상 스터디룸 Row를 Lock하도록 처리
- 동일 Room에 대한 예약 요청을 순차적으로 검증하도록 구조 보완
- 전일 TC-083 `동일 스터디룸 동시 예약 방지` 실패 결함 대응

#### Reservation Scheduler

- 스터디룸 이용 중 Backend가 중단되고 날짜가 변경될 경우 기존 예약이 계속 `IN_USE` 상태로 남는 문제 수정
- `CONFIRMED`, `IN_USE` 상태 예약을 날짜 기준으로 추가 확인하도록 Scheduler 보완
- 예약일이 이미 지난 예약은 `COMPLETED`로 자동 변경
- 지난 예약의 스터디룸 상태를 `AVB`로 복구
- 연결된 TicketUsage를 `EXPIRED` 처리
- 이미 `EXPIRED`, `CANCELED` 상태인 TicketUsage는 중복 만료 처리하지 않도록 검증
- 오늘 예약과 지난 예약의 상태 변경 로직을 구분하여 처리

#### Reservation Time

- 전일 김수영이 발견한 심야시간 예약의 `endHour=0` 문제 수정
- 스터디룸 종료시간 계산 시 `23:00 + 1시간`이 JavaScript Date 처리로 `00:00`이 되는 원인 확인
- Date Object 기반 시간 계산 제거
- 선택 시간의 Hour 값에 직접 1을 더하도록 `addOneHour()` 수정
- `23:00` 선택 시 종료시간이 `24:00`으로 유지되도록 보완

#### Reservation Refresh

- 예약 페이지 새로고침 시 Zustand Store의 Room 정보가 사라져 화면 데이터가 유실되는 문제 수정
- 예약 Route를 `/room/reservation/:roomId` 구조로 변경
- 좌석/스터디룸 선택 시 Room ID를 URL Parameter로 함께 전달
- 예약 페이지에서 `useParams()`로 Room ID 조회
- Store Room ID가 없을 경우 URL의 Room ID를 사용하도록 Fallback 처리
- 페이지 진입 시 Room 목록을 다시 조회하도록 `fetchRooms()` 호출
- 새로고침 후에도 선택 Room과 예약 가능 시간을 복원할 수 있도록 구조 보완

## 💬 주요 논의 및 결정

### 스터디룸 동시 예약 제어

- 전일 TC-083 테스트에서 동일 Room·동일 시간대에 복수 예약이 생성될 수 있는 문제 확인
- 단순 중복 여부 조회만으로는 거의 동시에 들어온 요청을 안전하게 차단하기 어렵다고 판단
- 예약 생성 시 해당 Meeting Room Row에 비관적 Lock을 적용하기로 결정
- 하나의 Transaction이 예약 검증 및 생성 작업을 진행하는 동안 동일 Room에 대한 다른 요청을 대기시키는 방식으로 동시성 문제 보완

### 예약 상태 복구

- Scheduler가 당일 예약만 조회할 경우 Server 중단 시점에 상태 변경 작업을 놓친 예약이 다음 날에도 `IN_USE`로 남을 수 있음을 확인
- 현재 날짜 이전의 `CONFIRMED`, `IN_USE` 예약도 조회하여 종료 상태로 정리하도록 변경
- 예약 종료 시 Reservation뿐 아니라 Room과 TicketUsage 상태도 함께 정리하여 도메인 상태 불일치 방지

### 예약 페이지 상태 유지

- 기존 예약 화면이 Zustand Store의 Room ID에 의존하여 새로고침 시 데이터가 소실되는 문제 확인
- 새로고침에도 복구 가능한 값을 URL에 포함하기로 결정
- 예약 Route에 `roomId`를 포함하고 Store가 초기화된 경우 URL 값을 기준으로 필요한 데이터를 재조회하도록 변경

### 인증 화면 공통화

- 로그인·회원가입·비회원 등록의 입력 및 인증 UI가 개별 Style로 관리되면서 Layout 차이가 발생
- 인증 관련 Input·Button·Timer·완료 Badge를 공통 CSS 구조로 통합
- 공통 인증 화면의 UI 규격을 일관되게 유지하도록 정리
