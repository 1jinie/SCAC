## 화면 플로우

### 로그인
```text
로그인 버튼
    ↓
사용자 인증
    ↓
메인화면
```

### 이용권 구매
```text
이용권 구매 버튼
    ↓
로그인 여부 확인
    ├─ 로그인 X → 비회원 정보 입력
    ↓                  │
    결제 ←─────────────┘
(비회원은 퇴실 시 이용권이 만료됨 안내)
(결제 완료시 자동 로그아웃)
    ↓
    메인화면
```
### 스터디룸 예약(회원전용)
```text
스터디룸 예약 버튼
    ↓
로그인
    ↓
좌석 배치 화면
    ↓
스터디룸 선택
    ↓
시간 선택
    ↓
결제
    ↓
결제 완료
    ↓
메인 화면
    ↓
입실 버튼을 통해 입실
```

### 회원가입
```text
회원가입 버튼
        ↓
전화번호 입력 (중복 확인)
        ↓
입실 비밀번호(6자리) 입력
        ↓
회원가입 완료
        ↓
메인 화면
```

### 퇴실
```text
퇴실 버튼
    ↓
회원 ID(전화번호) 입력
    ↓
입실 비밀번호 입력
    ↓
퇴실 처리
    ↓
출입문 개방
```

### 입실
```text
입실 버튼
    ↓
자리선택
    ↓
(유저 아이디(전화번호) 입력)
입실 비밀번호 입력
    ↓
출입문 개방
```

### 로그인, 입실, 이용권 구매 플로우 회의

#### 1안 (채택)
- **로그인**클릭-> 인증 -> 메인
- **입실**클릭 -> 자리선택 -> 입실 비밀번호
- **이용권 구매**클릭 -> 로그인 o -> 결제 -> 완료 후 자동 로그아웃 -> 메인
- **이용권 구매**클릭 -> 로그인 x -> 비회원 정보 입력 -> 결제 -> 메인  
- **퇴실**클릭 -> 입실 비밀번호 입력 -> 메인

#### 2안
- **로그인** 클릭 -> 인증 -> 좌석선택 -> 이용권이 있다면 있음 - 입실 없음 - 이용권 선택 화면 -> 결제 -> 입실    
- **이용권 구매** 클릭(비회원 전용) -> (비회원만)좌석배치 화면 -> 좌석 선택 )-> 이용권 선택 -> 결제 (비회원은 퇴실 시 이용권이 만료됩니다. 메시지)-> 입실  
- **퇴실** 클릭 -> 고유 사용자 ID(전화번호) 와 입실 비밀번호 입력 -> 퇴실처리 -> 문 열림  
- **입실** 클릭 -> 고유 사용자ID(전화번호)와 입실 비밀번호 입력 -> 좌석 선택 -> 입실

#### 3안
- **로그인**완료 -> 자리선택(+메인가기 버튼) -> 사용할 이용권 목록 표시 (+이용권 추가구매 버튼) -> 이용권 선택 -> 입실   
- **입실**클릭 -> 자리선택 -> 
비회원: 이용권 구매 화면 -> 구매완료 -> 전화번호 입실 비밀번호 입력 -> 입실  
로그인유저 : 사용할 이용권 목록 화면(+이용권 추가구매버튼) -> 이용권 선택 -> 입실
