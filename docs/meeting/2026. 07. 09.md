## 🎯 결정 사항 & Action

#### 프로젝트 구조
- React 프로젝트 디렉터리 구조를 확정
- 기능별 디렉터리(`api`, `components`, `pages`, `store`, `styles` 등)를 분리하여 관리하기로 결정
- 공통 컴포넌트와 페이지 전용 컴포넌트를 구분하여 작성하기로 함

#### 개발 컨벤션
- 프로젝트 전반에서 사용할 네이밍 규칙을 확정
- 코드 스타일(들여쓰기, 문자열, 세미콜론 등)을 통일하기로 결정
- API는 Axios Instance를 활용하여 `api` 폴더에서 관리하기로 결정
- Zustand는 기능별 Store를 생성하여 상태를 관리하기로 결정
- Git Branch 및 Commit Convention을 확정하여 협업 기준을 마련

#### 개발 진행
- 기능별 담당자별 화면 개발을 시작
- 기본 화면(UI Skeleton) 제작 후 세부 기능을 순차적으로 구현하기로 결정
