### 👤 장원진

### 좌석 / 예약 / 입실·퇴실 · 이용권 연장

#### TicketUsage Priority

* 다음 이용권 자동 전환 시 기간권 우선 정책 보완
* 다음 이용권 조회 순서를 아래와 같이 변경

  1. `READY` 기간권
  2. `READY` 시간권
* 동일 유형 이용권은 구매일이 오래된 순서로 우선 적용

#### 시간권 → 기간권 전환 오류 수정

* 시간권 사용 중 기간권으로 전환될 때 Check-in의 `usage_id`가 변경되지 않던 오류 수정
* 새 기간권을 저장한 뒤 발급된 실제 `usageId`를 사용하도록 처리
* 현재 `USING` 또는 `AWAY` 상태의 Check-in 조회
* 현재 Check-in의 `usage_id`를 새 기간권의 `usageId`로 변경
* 실제 사용 중인 이용권과 Check-in 참조 이용권이 일치하도록 보완

#### 기간권 추가 구매

* 기간권 사용 중 추가 기간권 구매 가능하도록 구현
* 현재 사용 중인 이용권이 기간권인 경우 새 기간권을 `READY` 상태로 대기
* 새 기간권의 시작시각을 기존 기간권 종료시각으로 설정
* 새 기간권의 종료시각을 시작시각 + `validDays`로 계산
* 여러 기간권이 동시에 소모되지 않고 순차적으로 이어서 사용되도록 처리
* 현재 사용 중인 이용권이 시간권인 경우 시간권을 `READY`로 변경하고 새 기간권 우선 적용
* 현재 사용 중인 이용권이 없는 경우 새 기간권을 바로 시작하도록 처리

#### TicketUsage

* 기간권 종료시각 계산 기준을 현재 시각이 아닌 `startAt` 기준으로 변경
* 미래에 사용 예정인 기간권도 정확한 종료시각을 가지도록 보완
* TicketUsage의 시작·종료시각 설정 기능 추가

### 👤 김수영

### 회원 / 인증 / 권한 · DB 관리

#### User Suspension

* DB의 `penalty_end_date DATE` 설계 기준에 맞게 회원 정지 해제 조건 수정
* 기존 `현재 날짜 > 정지 종료일` 조건을 `현재 날짜 >= 정지 종료일` 조건으로 변경
* 정지 종료 당일부터 회원 상태를 `ACTIVE`로 복구할 수 있도록 수정
* 정지 해제 시 `penaltyEndDate` 초기화

#### Authentication

* 사용자 로그인 시 `checkAndReleaseSuspension()` 실행
* 정지 기간이 종료된 회원은 로그인 과정에서 실시간으로 계정 정상화
* Refresh Token을 이용한 토큰 재발급 과정에서도 정지 종료 여부 확인
* Scheduler 실행 전이라도 로그인 또는 토큰 재발급 시 정상 상태로 복구
* `BANNED` 상태 사용자는 기존과 동일하게 인증 차단
