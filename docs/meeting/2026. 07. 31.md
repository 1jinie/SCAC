### 👤 김수영  
### 회원 / 인증 / 권한 · DB 관리

#### User Authentication

- 로그인 요청 전 전화번호 하이픈 제거
- Access Token과 Refresh Token을 LocalStorage에 저장
- 로그인 사용자 정보를 LocalStorage에 저장
- 새로고침 후 LocalStorage를 기준으로 인증 상태 복구
- 일반 사용자 로그인과 관리자 로그인 Store 로직 분리
- 회원가입·비회원 등록 API를 사용자 API 영역으로 분리
- 로그아웃 시 LocalStorage와 인증 상태 초기화
- 만료되거나 손상된 Access Token으로 로그아웃해도 정상 처리되도록 보완

#### Token Refresh

- Axios Response Interceptor 구현
- API 요청에서 401 발생 시 Refresh Token을 이용한 자동 재발급
- 재발급 성공 시 새 Access Token 및 Refresh Token 저장
- 실패했던 기존 요청에 새 Token을 적용하여 자동 재요청
- Refresh Token이 없거나 재발급에 실패하면 로그인 화면으로 이동
- 만료된 JWT에서도 Claims를 조회할 수 있도록 JwtProvider 보완

#### Security

- 영구 정지 회원 접근 시 403 응답 처리
- 일시 정지 회원 접근 시 정지 종료일을 포함한 403 응답 처리
- JWT Filter에서 공통 JSON 오류 응답 반환
- 공개 API와 인증 필요 API 설정 재정리
- 입실 비밀번호 변경 API를 인증된 사용자만 호출하도록 설정
- 권한이 없는 접근에 대한 `AccessDeniedException` 처리 추가

#### Admin Authentication

- 관리자 로그인 API 경로 정리
- 관리자 로그아웃 API 경로 정리
- 관리자 계정 및 비밀번호 검증
- 관리자 로그인 시 마지막 로그인 시간 갱신
- 관리자 Access Token 및 Refresh Token 발급
- Access Token이 없으면 관리자 로그인 화면으로 이동하도록 Private Route 적용
- 관리자 사용자 관리 API 경로를 `/api/admin/users/**`로 통일
- 관리자 인증 Store 기본 구조 생성

#### User / My Page

- 사용자 응답 DTO에 현재 이용권명 필드 추가
- 사용자 프로필 조회 Service 분리
- 마이페이지에서 인증 Store의 사용자 ID 사용
- Frontend에서 현재 비밀번호를 직접 비교하던 로직 제거
- 현재 비밀번호와 새 비밀번호를 Backend에서 검증하도록 변경
- 비밀번호 변경 성공 후 자동 로그아웃 처리
- 회원가입과 비회원 등록 시 전화번호 정규화 강화
- 회원가입 화면의 입력값 및 오류 처리 보완

#### Admin

- 관리자 사용자 관리 Controller 및 Service 기본 구조 생성
- 관리자 대시보드 Service 및 응답 구조 생성

## 🗄️ DB 변경 사항

### Ticket 데이터 정합성 수정

- `ticket_table`에서 `ticket_type`이 `TIME_PACK`임에도 `valid_days` 값이 저장되어 있던 데이터 확인
- 시간권 데이터의 `valid_days` 값을 `NULL`로 수정
- 시간권과 기간권의 컬럼 사용 기준을 다음과 같이 정리
  - `TIME_PACK`
    - `ticket_time` 사용
    - `valid_days`는 `NULL`
  - `PERIOD_PACK`
    - `valid_days` 사용
    - `ticket_time`은 `NULL`

> 테이블 컬럼이나 제약조건 변경은 없으며, 기존 데이터 정합성 수정을 진행함
